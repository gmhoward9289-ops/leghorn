# Performance audits

Dated observational checks of leghorn's cost under load. Each subdirectory is
one sitting: a verdict, raw numbers, the script that produced them, and the
console log.

These are not CI benchmarks and are not run on every commit. They exist so a
"is leghorn making the box lag?" question has a written answer with numbers.
